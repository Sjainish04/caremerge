## Wiring tools into Claude Code — once the track is chosen

Not pre-configured on purpose. Each server sends queries to a vendor or touches user-level config, so opt in per track.

| Track | Command (run from the repo root) | Notes |
| --- | --- | --- |
| Fire TV | `claude mcp add --scope project amazon-devices-buildertools-mcp -- npx -y @amazon-devices/amazon-devices-buildertools-mcp@latest` | Project-only alternative to the official `init-context` installer, which edits `~/.claude`. Proprietary package; doc-search queries go to Amazon; fails on Node 26 — use Node 24 |
| Ring | `claude mcp add --scope project --transport http ring-knowledge https://knowledge.appstore-mcp.ring.amazon.dev/mcp` | Ring's knowledge MCP server; check the [Ring MCP page](https://developer.amazon.com/docs/ring/ring-mcp.html) for auth first |
| Bee | `bee mcp connect claude-code` | Needs `npm i -g @beeai/cli`, Developer Mode, and `bee login`; exposes personal data to the agent |
| Alexa+ | `/plugin marketplace add modelcontextprotocol/ext-apps` (inside Claude Code) | MCP Apps scaffolding skills — the hackathon's "Build with Agent Skills" link |
